# 无器械五分化薄肌训练打卡应用

一个基于 Flask 的居家健身打卡 Web 应用，将抖音健身视频"自律的黑"的无器械三分化训练内容扩展为五分化训练计划，提供日历打卡、动作图文指导、训练进度统计等功能，类似 Keep 的界面体验。

## 项目介绍

### 功能特性

- **日历打卡视图**：8 周 56 天训练计划，可视化展示每日训练安排
- **五分化训练**：肩部 → 腹部 → 胸部 → 背部 → 腿部 → 休息，6 天一循环
- **三阶段进阶**：每个部位提供初级/中级/高级三个阶段的动作选择
- **图文指导**：每个动作包含示范图、动作要点、组数次数、视频教程链接
- **打卡管理**：点击完成后项目移至"已完成"，支持撤销
- **进度统计**：累计打卡天数、本周完成率、连续打卡天数
- **本地数据存储**：打卡记录保存在本地 JSON 文件，无需数据库

### 技术栈

- **后端**：Python + Flask
- **前端**：原生 HTML / CSS / JavaScript（无框架依赖）
- **数据存储**：JSON 文件
- **图片资源**：本地静态文件（无需网络即可加载）

## 快速开始

### 环境要求

- Python 3.7+
- Flask 2.0+

### 安装依赖

```bash
pip install flask
```

或使用 requirements.txt：

```bash
pip install -r requirements.txt
```

### 启动应用

#### 方式一：一键启动（推荐 Windows 用户）

双击 `start.bat`，脚本会自动检测 Python 并启动应用，浏览器将在 2 秒后自动打开。

#### 方式二：命令行启动

```bash
cd goodbody
python app.py
```

启动成功后访问：http://127.0.0.1:5000

#### 方式三：创建桌面快捷方式

双击 `创建快捷方式.bat`，会在项目目录生成 `健身打卡.lnk` 快捷方式，以后双击快捷方式即可启动。

### 关闭应用

关闭运行应用的终端窗口即可停止服务。

## 训练计划说明

### 五分化循环

| 天数 | 训练部位 | 可选动作（三阶段） |
|------|---------|-------------------|
| Day 1 | 肩部 | 跪姿冲肩俯卧撑 / 标准冲肩俯卧撑 / 折刀俯卧撑 |
| Day 2 | 腹部 | 平板支撑 / 西西里卷腹 / 俯身开合跳 |
| Day 3 | 胸部 | 跪姿俯卧撑 / 标准俯卧撑 / 下斜俯卧撑 |
| Day 4 | 背部 | 门框划船 / 毛巾划船 / 反向划船或引体向上 |
| Day 5 | 腿部 | 徒手深蹲+提踵 / 保加利亚分腿蹲+提踵 / 跳跃深蹲+提踵 |
| Day 6 | 休息 | - |

每 6 天循环一次，共 8 周 56 天。

### 进阶建议

新手从第一阶段开始，满足以下条件可进阶：
- 连续两次训练轻松完成目标组数
- 最后一组仍有 1~2 次余力
- 无关节疼痛

## 使用指南

1. **查看日历**：左侧日历显示训练计划，已完成日期高亮，今日有边框提示
2. **选择日期**：点击任意日期查看当天训练任务
3. **查看指导**：点击"图文指导"按钮查看动作详情（示范图、要点、视频链接）
4. **完成打卡**：点击"完成"按钮，项目移至"已完成"区域
5. **撤销打卡**：在"已完成"区域点击"撤销"可恢复为未完成

## 数据说明

- 训练计划和动作详情存储在 `data/` 目录的 JSON 文件中
- 打卡记录自动保存在 `data/checkin_record.json`（已加入 .gitignore，不会上传到 GitHub）
- 如需重置打卡记录，删除 `checkin_record.json` 或将其内容改为 `{"records": {}}`
